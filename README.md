# Автоматизация API-тестирования

Учебный проект по автоматизации тестирования REST API сервиса Swagger Petstore с использованием Python, pytest и requests.

Проект включает автоматизированные проверки создания, получения, обновления и удаления данных питомца, а также проверку ответа API при запросе несуществующего питомца.

## Используемые технологии

- **Python** — язык программирования, на котором написаны тесты.
- **pytest** — фреймворк для запуска тестов и проверки результатов.
- **requests** — библиотека для отправки HTTP-запросов к API.
- **pytest-html** — плагин для генерации HTML-отчётов о результатах тестирования.

## Структура проекта

```text
PythonTestAPIpets/
├── tests/
│   └── test_api.py
├── utils/
│   └── api_client.py
├── .gitignore
├── main.py
├── requirements.txt
└── README.md
```

- `tests/test_api.py` — автоматизированные API-тесты.
- `utils/api_client.py` — вспомогательный класс для отправки HTTP-запросов.
- `requirements.txt` — список зависимостей проекта.
- `.gitignore` — список файлов и папок, которые Git должен игнорировать.
- `main.py` — стартовый файл Python, созданный шаблоном PyCharm.
- `README.md` — описание проекта и инструкция по запуску.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Daniil91-prog/PythonTestAPIpets.git
cd PythonTestAPIpets
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск тестов

```bash
python -m pytest
```

**Примечание:** тесты обращаются к публичному API Swagger Petstore. Доступность сервиса зависит от сети; в некоторых условиях может потребоваться VPN.
